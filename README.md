## аннотация

proteus это детерминированный headless планировщик tcp портов, метка
которого в режиме bio читается из модели коннектома червя (279 нейронов,
graded potentials, модуляция серотонином, октопамином и дофамином, тело с
мышцами). движок petri написан с нуля и вендорится в `src/petri/`. весь
измерительный путь headless: сокетов он не открывает, живой путь от
журнала расходится, и это заявлено явно. полный текст исследования с
методами, статистикой и перечнем отозванных утверждений:
[paper/FINAL.md](paper/FINAL.md).

научный результат отрицательный и в этом ценность: все защитные свойства
опровергнуты измерениями, каждое число трассируется до команды.

## ключевые измерения

| величина | значение | n | примечание |
|---|---|---|---|
| частота ходов в тишине | mean 97.5 за 600 s, t-CI [79.7, 115.3] | 10 сидов | полоса [100, 300] промахнута, записано |
| ложные тревоги детектора | 8 за 6000 s, Byar CI [0.34, 1.58] | 10 x 600 s | бюджет соблюдён |
| детекция вспышки | 3/10 в окне 3 s, Wilson [0.108, 0.603] | 10 журналов | 8/10 отозвано: 5 из 8 срабатываний до стимула |
| порог детектора | 50.0 | заморожен | наименьший узел сетки с FA в бюджете |
| обучаемость L, пассивный атакующий | cycle 88/100 при L=65, bio 0/100, random 0/100 | 100 партий | длины партий 44..155, cap 500 не достигнут |
| маргинальная энтропия H, n=20 | bio 4.014 [3.885, 4.136] против random 5.468 [5.402, 5.539] | 20 журналов | bio предсказуемее random |
| held out accuracy, n=20 | bio 0.0712 [0.0540, 0.0901] против random 0.0100 [0.0047, 0.0158] | 20 журналов | uniform 0.0156 |
| восстановление seed | 3 наблюдённых порта, 0.6 s, диапазон 2x10^5 | 1 сид с знанием кода | вслепую 0/20 |
| no-op ходы | 15.1% из 10048 | 100 журналов | ход без смены порта |

каждое число пересчитывается `tools/paper_stats.py`, вывод в
`results/paper_stats.txt`. массовые журналы (1.3 GB) вынесены из git в
zenodo архив, см. [results/BULK_DATA.md](results/BULK_DATA.md).

## опровержения, которые держит проект

- биология не случайнее ГПСЧ: при алфавите 64 символа потолок 6 бит на
  ход, а метрика L насыщается для почти равномерных источников;
- random-армия сломана на уровне политики seed: xorshift64* зная код
  восстанавливается по 3 портам, `tools/seed_recovery_attack.py`;
- bio readout ранга 1: среднее шести скаляров, даёт 16 различимых портов
  из 64; это дефект readout, не коннектома;
- детектор меряет не вспышку: детекция 8/10 отозвана, валидна только
  оценка 3/10 в окне 3 s;
- тайминг режимонезависим: момент хода задаёт рефлекс скорости тела и
  фильтр avb, режим выбирает только метку.

четыре ещё выигрываемых утверждения и эксперименты к ним:
[docs/PLAN_V11.md](docs/PLAN_V11.md).

## сборка и запуск

```bash
make                       # cc -std=c99 -pedantic -Wall -Wextra -Werror -O2
make test                  # unit + детерминизм реплея

# headless партия, журнал в файл
./proteusd -s 1 -d 60 -e tests/fixtures/burst.csv -o /tmp/party.csv

# режим назначения: cycle (счётчик) | bio (коннектом) | random
./proteusd -s 1 -d 60 -e tests/fixtures/burst.csv --dest-mode bio

# живой слушатель с ipc управляющим сокетом
./proteusd -s 1 -d 600 --listen --socket /tmp/p.sock -o /tmp/party.csv
./proteusctl status --socket /tmp/p.sock
```

## архитектура

| компонент | роль |
|---|---|
| `src/petri/` | вендоренный движок коннектома v1.2: 279 нейронов, graded potentials, stsp, модуляторы, физика тела |
| bridge | владение движком, мембранный шум, инъекция модуляторов, readout состояния |
| detector | согласованный фильтр по avb, окно 1 s, замороженный порог |
| reflex | определение реверса движком: скорость < 0.02 mm/s 500 ms |
| motor | окно портов 40000..40063, неблокирующий слушатель |
| sensor | неблокирующий accept, классификация payload, ban список |
| nft | netlink (libmnl) вручную, таблица `proteus`, множество `banned` |
| seccomp | bpf фильтр на 31 syscall из статического strace |
| ipc | SOCK_SEQPACKET, SO_PEERCRED, групповая авторизация |
| journal | csv из 11 колонок, версионируемый, строка на 10 ms модельного времени |

## воспроизводимость

каждый прогон фиксирует sha256 бинарника, коммит, компилятор, флаги,
диапазон сидов и хэш файла событий. реплей бит в бит:

```bash
./proteusd -s 42 -d 600 -e tests/fixtures/burst.csv -o a.csv
./proteusd -s 42 -d 600 -e tests/fixtures/burst.csv -o b.csv
cmp a.csv b.csv && echo "bitwise identical"
```

манифест релиза: `results/manifest.txt` (коммит, компилятор, флаги,
sha256 всех артефактов). честные границы: реплей верифицирован на одной
связке компилятор и libm; кроссплатформенная побитовая идентичность не
заявляется до замены libm собственным слоем.

## использование ИИ

заявление по практике icmje/elsevier: инструменты на базе больших
языковых моделей использовались как вспомогательные для редактирования
текста документации, генерации вспомогательных скриптов и визуализации.
весь научный замысел, код движка petri, все измерения, интерпретации и
решения выполнены автором. ИИ не является автором, ответственность за
содержание несёт человек. детали: [paper/AI_ASSISTANCE.md](paper/AI_ASSISTANCE.md).
