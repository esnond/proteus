## Abstract

Moving Target Defense (MTD) aims to increase attacker uncertainty by dynamically changing the attack surface. We present **Proteus**, an MTD system where the port-hopping schedule is generated by a living *C. elegans* connectome simulation (petri engine, vendored), not a seeded PRNG. The defense schedule is a function of a nervous system's internal state: nociception (ASH), command interneurons (AVA/AVB), and neuromodulators (serotonin, octopamine, dopamine). We formalize **learnability L** — the minimum observations for an observer to predict the next port with P ≥ 0.9 — as a unified metric spanning MTD and neuroscience. Six attacker models (A1–A6) are defined with precise capabilities. In sandbox validation (r2): detector matched-filter achieves 7/10 detection at frozen threshold 30.0 (FA 1/600s, Wilson CI [0.40,0.89]); ban mechanism holds 100% of fires; wire-level low-and-slow detection rate 1/3 (published boundary); idle CPU 7% (realtime tick), throughput 250 sess/s headless vs 33 sess/s realtime. r3 atlas infrastructure and g1–g7 observer models are built; hypotheses are registered pre-experiment with falsification criteria. **Limitations:** nftables kernel acceptance unvalidated (privileged bench required), g4 active probe requires netns, robot body excluded. This is a research prototype + hypothesis test, not a certified firewall.

## 1. Introduction

Moving Target Defense (MTD) has been proposed as a paradigm to shift the asymmetry favoring attackers [Jajodia 2011, Zhu 2011]. Most MTD systems use algorithmic port/IP hopping — seeded PRNGs, deterministic permutations, or game-theoretic schedules [Ghosh 2019]. The central problem: **if the schedule is generated by a deterministic algorithm, an observer who reconstructs the algorithm wins** (L = seed recovery time).

Proteus takes a different approach: the schedule is the **behavioral output of a living nervous system**. The *C. elegans* connectome (302 neurons, ~7000 synapses) is simulated in real time; port moves occur when the command circuit (AVA/AVB) triggers a reversal, modulated by serotonin (food), octopamine (roaming), and dopamine (mechanical contact). The detector is a matched filter on AVA deviation from adapted baseline. No `if (scan) ban` rules exist in the science path — the defense emerges from connectome dynamics.

**Contributions:**
1. **Bio-stochastic MTD**: Schedule = connectome behavior, not PRNG.
2. **Unified learnability metric L** applied to both MTD schedules and worm behavior.
3. **Formal threat model** with 6 attacker classes (A1–A6), capabilities, win conditions.
4. **Registered hypotheses g1–g7** with pre-experiment falsification criteria.
5. **Honest publication**: negative results, environment blocks, and boundaries documented.

## 2. Formal Threat Model

We define six attacker models with **precise capabilities and win conditions**. The defender's goal: maximize L (observations needed for P(next_port) ≥ 0.9). The attacker's goal: minimize L.

### A1 Passive Observer
- **Capabilities**: Observes port sequence (timestamp, port) via legitimate connections or side channel. No active interaction. Knows proteus algorithm (open source), connectome topology, frozen constants. Does NOT know seed.
- **Goal**: Predict next port.
- **Win condition**: L ≤ threshold (e.g., L < 100 observations).

### A2 Active Prober
- **Capabilities**: A1 + sends probe connections to chosen ports, observes accept/refuse/ban. Budget: C probes per time window. Observes timing side channels (ban latency).
- **Goal**: Reduce L below passive bound.
- **Win condition**: L_active < L_passive with statistical significance (p < 0.01, Bonferroni).

### A3 Insider (Topology Knowledge)
- **Capabilities**: A1 + knows exact connectome topology, synaptic weights, all frozen constants (config.h). Does NOT know seed or runtime modulator state.
- **Goal**: Reconstruct generator (seed or schedule parameters).
- **Win condition**: Generator reconstruction success rate > 50% within probe budget.

### A4 Co-resident (Side Channels)
- **Capabilities**: A1 + same host. Access to CPU timing, cache, memory pressure, IPC socket (if group member). Can measure realtime tick jitter.
- **Goal**: Extract internal state (modulators, detector score, AVA phase) via side channels.
- **Win condition**: Mutual information I(side_channel ; internal_state) > threshold.

### A5 Network Adversary (Routing Control)
- **Capabilities**: Controls network path (BGP hijack, DNS, MITM). Can delay, drop, replay, inject packets. Observes wire-level scan detection rate.
- **Goal**: Disrupt legitimate traffic > 1% while avoiding ban; or learn schedule despite network interference.
- **Win condition**: Legitimate disruption > 1% OR schedule learned despite interference.

### A6 Quantum (Theoretical Bound)
- **Capabilities**: Bounded by physics. Not assumed to break classical crypto or reconstruct xorshift64* faster than Grover.
- **Goal**: Theoretical lower bound on L.
- **Win condition**: N/A — this model establishes **upper bounds on defender claims**. We do NOT claim quantum resistance.

**Out of scope:** Physical access, supply chain, kernel exploits, social engineering.

## 3. System Model

### 3.1 Connectome Engine (petri, vendored, commit b436adb)
- 302 neurons, graded potential model, Tsodyks-Markram STSP (depressing/facilitating)
- Homeostatic scaling (τ=600s), heterosynaptic aversive learning (η=0.004, τ=20s)
- Neuromodulators: SER τ=6s, OCT τ=5s, DOP τ=2.5s (engine kinetics = decay)
- Mechanosensation: MEC_G=10, ASH τ=2500ms (nociceptor envelope)
- Spike-frequency adaptation: ADAPT τ=2000ms, GAIN=9mV

### 3.2 Bridge (proteus/src/bridge.c)
- `noise_scale = 1.0` (engine default 0 → all seeds identical)
- Phantom wall tap at t=0 primed: `prev_contact = prev_nose_contact = 1`
- `bridge_ash(t)`: ASH_TRACE amplitude passed to engine
- `bridge_steps(n)`: advances simulation by n × TICK_MS (10ms)

### 3.3 Detector (matched filter, r1)
- Window: 1000ms dense (DET_WINDOW_TICKS=100)
- Baseline: EMA τ=30000ms (DET_BASE_TAU_MS), seeded from first AVA reading
- Score: Σ(ava - baseline) over window
- Threshold: DET_THRESHOLD = 30.0 (frozen, lowest grid with FA ≤ 1/600s)
- States: ARMED → FIRED (score ≥ threshold) → COOL (10000ms) → ARMED
- Journal events: det_armed (3), det_fired (2), det_cool (1)

### 3.4 Modulator Injection (r1)
- Octopamine: `oct += OCT_INJ_PER_HZ × density × dt` (0.040 Hz⁻¹)
- Serotonin: `ser += SER_INJ_PER_SHARE × share × dt` (0.120)
- Clamped [0,1]; engine kinetics = decay
- hunger > fed on 10/10 seeds at 0.5/1/2/4 Hz

### 3.5 Port Move (motor)
- Union of causes: endogenous (reflex, AVA threshold) | detector (cause|=2)
- Deterministic walk: PORT_BASE=40000, PORT_WINDOW=64, AVA_MOVE_THR=0.75, cooldown=2000ms
- Journal: cause (0=none,1=endogenous,2=detector,3=both), event (1=burst,2=legit,3=det_armed,4=det_fired,5=det_cool,6=net_scan,7=net_session,8=ban)

### 3.6 Ban Mechanism
- Userspace: circular TTL list (BAN_TTL_MS=60000), checked at accept
- nftables (r2): libmnl netlink, table `proteus` inet, set `banned` ipv4, batch atomic
- Kernel enforcement requires CAP_NET_ADMIN (unvalidated in sandbox)

### 3.7 Journal v2 (frozen)
```
t_ms,act_ava,act_avb,ash_trace,ser,oct,dop,det_score,port,cause,event
```

### 3.8 IPC
- SOCK_SEQPACKET, SO_PEERCRED, owner or group members (no root required)
- Commands: status, log, party, detector

## 4. Learnability Metric L

**Definition (theory.md г5):**
> L = minimum number of surface observations after which observer model predicts next defense move with probability ≥ 0.9.

**Measurement protocol:**
1. Observer receives sequential port observations (timestamp, port).
2. After each observation, observer outputs P(next_port = p) for all p ∈ [40000, 40063].
3. L = first n where max_p P(next_port = p) ≥ 0.9.
4. If never reached within trace, L = ∞.

**Applied to each attacker:**
- A1: Passive frequency/transition matrix → L_passive
- A2: Active probes → L_active (probes count toward budget)
- A3: Generator reconstruction → L_reconstruction (seed/param recovery)
- A4: Side-channel augmented → L_side
- A5: Network-interfered observations → L_net
- A6: Theoretical bound → L_quantum

**Statistical rigor:** Bootstrap 95% CI (1000 resamples), Cohen's d for pairwise, Bonferroni across 7 hypotheses (α = 0.0071).

### 5.3 Falsification Criteria (registered pre-experiment)
| Hypothesis | Falsified if |
|------------|-------------|
| g1 (flat < bio) | Median L_flat ≤ Median L_bio |
| g2 (active < passive) | L_active ≥ L_passive (p ≥ 0.0071) |
| g3 (anonymity) | Recognition time ∝̸ 1/frequency (p ≥ 0.0071) |
| g4 (active probe) | L_active ≥ L_passive (netns required) |
| g5 (economic) | Cost(L) not monotonic (p ≥ 0.0071) |
| g6 (collapse) | Transfer gap = 0 (independent stand needed) |
| g7 (central) | L_bio < 10×L_seeded OR legit disruption > 1% |

### 5.4 Atlas Divergence (r3)
- Two halves (0–300s, 300–600s)
- 14-driver attribution vector per move
- Sparse logistic regression (L1, 5-fold CV) per half
- 4 divergence flags (Jaccard, cosine, rank, mass) with Bonferroni α=0.0125

## 9. Conclusion

Proteus demonstrates that a **living connectome can drive a moving target defense** with measurable learnability properties. The r2 validation passes in sandbox with documented environment blocks. The r3 atlas + g1–g7 framework provides a **falsifiable experimental pipeline** — every hypothesis has a registered falsification criterion, held-out seeds are strictly separated, and negative results are published with data.

**What was learned (not claimed proven):**
- Bio-stochastic schedules have measurable L against passive observers.
- Detector threshold calibrated on FA budget yields probabilistic detection (7/10 fixture, 1/3 wire).
- Ban mechanism holds 100% where it fires.
- Realtime tick cost dominates idle CPU (7% vs <1% target).
- nftables netlink protocol works in userspace; kernel acceptance unvalidated.

**What remains:**
- Privileged bench: nftables enforcement, g4 active probe, g6 transfer gap.
- r3 atlas + g1–g7 full sweep on training/held-out seeds.
- If g7 holds (L_bio ≥ 10×L_seeded, disruption < 1%), proceed to main-track submission.
