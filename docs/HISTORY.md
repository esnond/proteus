# история проекта в коммитах

хронология от прототипа до закрытия гипотез. две опубликованные истории:
движок petri в github.com/esnond/petri и защита proteus здесь. обе
истории начинаются 2026-10-28 с даты публикации репозиториев; до этого
разработка шла в рабочем каталоге без опубликованных коммитов. история
proteus насчитывает 70 коммитов за 3 дня.

## чем закончились гипотезы

| гипотеза | вердикт |
|---|---|
| h2, коннектом решает что | опровергнута: назначение было счётчиком, 100% восходящий цикл, L=65 |
| h5, усталость от длительной дозы | не опровергнута: dz=-0.13, p=0.564, эффект не найден |
| h9, обучаемость расписаний | главная часть подтверждена: bio 0/100, random 0/100, cycle 88/100 при L=65; 2 критерия провалились (короткие партии, no-op 15.1%) |
| h10, связка рефлекса | 1 из 2: порог 50.0 заморожен, полоса хода промахнута (97.5 против [100, 300]) |
| h11, разведка | post hoc: seed восстанавливается по 3 портам за 0.6 s с знанием кода, вслепую 0/20 |
| h12..h15 | не запускались, включая h13 coupling: данных нет, заявлений нет |

итог: ни одно защитное свойство не выдержало проверки. научный выход
проекта это каталог опровержений с трассируемыми числами, воспроизводимый
артефакт и методика; полный текст в paper/FINAL.md, вердикты в
docs/hypotheses_results.md.
