# roadmap

сюда попадают только идеи вне текущего промта, с датой. реализация
каждого пункта требует явного решения владельца.

## 2026-10-28

- предложение движку petri (вверх по потоку): поведенческий выход
  ноцицепции — реверс на касание — не выражен, задокументировано в
  записке petri (3c, verdict mismatch). кандидат: перекалибровка связи
  цепи ash→avd→ava при сохранении stsp. proteus это не чинит сам:
  движок не переписывается.
- модель пачки сканирования как поезд пакетов с межпакетными паузами
  вместо sustained-приложения: stsp-динамика поезда отличается, плотность
  кодируется частотой, а не амплитудой. потребует расширения схемы
  событий (v2, ломающее изменение контракта csv).
- измерение стоимости сим-шага (бюджет 1 мс на cortex-a7, ворота р2)
  на целевой платформе, не только на сборочной машине.
- proteusctl: ipc к живому демону (unix socket) вместо разбора журналов.
- сглаживание доли разорванных легитимных соединений как первичной
  метрики атласа р3 рядом с L.
